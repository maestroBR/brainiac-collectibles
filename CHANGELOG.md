# Changelog

## 1.3.1

- Individual lore descriptions for all 30 collectibles in five languages.
- Asset credits remain in CREDITS.md instead of item descriptions.
- Item IDs, loot and prices unchanged.


## 1.3.0

- English, German, Russian, Brazilian Portuguese and Simplified Chinese item translations.
- Revised short names to avoid truncated words.
- Localization validation before item registration.
- Item IDs and GUID preserved; compatible with the Weekend addon.

## 1.2.0

- Standalone main mod, with no Weekend dependency.
- Preserved all 30 item IDs and bundles from 1.1.0.
- Normalized map keys when adding loot pools.
- Added source, catalogue, credits and release packaging.
